# Pinnacle Tracker

Отслеживание движения коэффициентов Pinnacle через [The Odds API](https://the-odds-api.com).

Отслеживаемые рынки Pinnacle: **П1 / X / П2**, **двойной шанс 1X / 12 / X2** (реальный), **тотал** и **фора** (основная линия),
**индивидуальные тоталы** (если Pinnacle их даёт — на футбол обычно нет).

- **Открытие линии**: каждые 15 минут бесплатно проверяется список матчей лиги; как только у Pinnacle появилась линия
  нового матча, снимаются все рынки (≈ 4–5 запросов квоты). Для только что добавленной лиги открытием считается первый опрос.
- **Плановый опрос**: 1X2 + тотал + фора одним запросом на лигу (3 запроса квоты).
- **Закрытие**: за час до старта снимается реальный двойной шанс вместе с 1X2 (≈ 2 запроса).
- Между открытием и закрытием двойной шанс (курсив) рассчитывается из 1X2 того же снимка: `1X = 1 / (1/П1 + 1/X)` —
  у Pinnacle он совпадает с реальным с точностью ~0.01.
- Для тотала и форы изменение считается по текущей линии; если линия сдвинулась (2.25 → 2.5), это показано отдельно.

- **Матчи** — текущий коэффициент и изменение от первого зафиксированного значения; клик — история всех снимков.
- **Просадки / Повышения** — исходы, у которых коэффициент упал / вырос от открытия на заданный % (по умолчанию ≥ 3%), с фильтром по рынку.
- **Лиги** — какие лиги опрашивать (с оценкой расхода квоты).

Фиксируется только прематч: после начала матча снимки не пишутся.
«Открытие» — первый снимок трекера: для новых матчей это 15–30 минут после появления линии у Pinnacle.

## Работа на GitHub (без своего сервера)

Опрос делает GitHub Actions (`.github/workflows/poll.yml`), сайт публикуется на GitHub Pages.

- Cron стартует каждые 15 минут, `python -m app.cli run` проверяет новые матчи, опрашивает лиги, которым пора,
  и снимает линии закрытия. Если ничего не изменилось — коммита нет.
- Состояние (все снимки) хранится в `data/state.json` и коммитится ботом после каждого опроса.
  Матчи, начавшиеся больше 14 дней назад, удаляются.
- Сайт — тот же `static/index.html`: если рядом лежит `data.json`, страница работает без бэкенда.

Настройка репозитория (один раз):
1. **Settings → Secrets and variables → Actions → Secrets**: `ODDS_API_KEY`.
2. **Settings → Secrets and variables → Actions → Variables**: `TRACK_SPORTS` (через запятую, например `soccer_epl,soccer_spain_la_liga`).
   Необязательно: `POLL_BASE_HOURS`, `POLL_NEAR_HOURS`, `NEAR_KICKOFF_HOURS`, `MIN_QUOTA_REMAINING`,
   `LEAGUE_MARKETS` (рынки планового опроса, по умолчанию `h2h,totals,spreads`; `h2h` — в 3 раза дешевле), `CLOSE_WINDOW_MIN`.
3. **Settings → Pages → Source: GitHub Actions**.
4. **Actions → Poll Pinnacle → Run workflow** (галочка «force» — опросить сразу).

Ограничения: запуски по cron могут опаздывать на 5–15 минут; на бесплатном плане Pages работает только у публичного репозитория.
В публичном репозитории GitHub может отключить расписание после 60 дней без активности — придёт письмо, включается одной кнопкой.

## Локальный запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать ODDS_API_KEY
.venv/bin/uvicorn app.main:app --port 8077
```

Открыть http://localhost:8077. Опрос идёт, пока запущен сервер; после перезапуска он продолжает по расписанию
(время последнего опроса хранится в БД `data/odds.sqlite`).

## Расписание и квота

Каждая лига опрашивается по своему расписанию:
- обычно раз в 3 часа (`POLL_BASE_HOURS`);
- если матч лиги начнётся в ближайшие 8 часов (`NEAR_KICKOFF_HOURS`) — раз в час (`POLL_NEAR_HOURS`), до начала матча.

Плановый опрос = по 1 запросу квоты за каждый вернувшийся рынок (`markets=h2h,totals,spreads` → 3) — в ответе сразу все матчи лиги.
Для лиги вроде EPL это ≈ 300–400 опросов/мес → ≈ 900–1200 запросов, плюс ≈ 7 на каждый матч (открытие и закрытие).
**Бесплатных 500/мес на это не хватает** — нужен платный план, либо `LEAGUE_MARKETS=h2h` (тотал и фора тогда только
на открытии). Список матчей и пустые ответы квоту не тратят. При остатке меньше `MIN_QUOTA_REMAINING` платные запросы останавливаются.

## Структура

- `app/poller.py` — фоновый опрос по расписанию
- `app/store.py` — SQLite (матчи, снимки, настройки)
- `app/movement.py` — изменение от открытия, просадки и повышения
- `app/markets.py` — разбор рынков API, расчёт двойного шанса
- `app/odds_client.py` — HTTP-клиент The Odds API
- `app/main.py` — FastAPI
- `static/index.html` — интерфейс
