# Odds Viewer

Таблица коэффициентов букмекеров (по умолчанию Pinnacle) через [The Odds API](https://the-odds-api.com).

Рынки: **П1 / X / П2** (+ маржа), **двойной шанс 1X / 12 / X2**, **общий тотал** (основная линия + все линии),
**индивидуальные тоталы** (по кнопке «показать» — отдельный запрос на матч).
Зелёным подсвечивается лучший коэффициент среди всех контор по матчу.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать ODDS_API_KEY; без ключа — демо-данные
.venv/bin/uvicorn app.main:app --port 8077
```

Открыть http://localhost:8077

## Тесты

```bash
.venv/bin/python -m pytest -q
```

## Квота API

- `/odds` стоит `кол-во рынков × кол-во регионов` (по умолчанию `h2h,totals` × `eu` = 2 запроса).
- Индивидуальные тоталы — отдельный запрос на матч (стоит 1 × регионы), поэтому грузятся только по клику.
- Ответы кэшируются на `CACHE_TTL_SECONDS` (по умолчанию 120 с). Список лиг — бесплатный.
- Двойной шанс у большинства контор в API не приходит, поэтому он считается из 1X2: `1X = 1 / (1/П1 + 1/X)`
  (в таблице выделен курсивом). Маржа конторы в нём сохраняется — это оценка, а не реальная линия.
- Индивидуальные тоталы (`team_totals`) в The Odds API покрыты в основном для американских видов спорта;
  по футболу у многих контор их может не быть.

## Структура

- `app/odds_client.py` — HTTP-клиент + кэш + учёт квоты
- `app/markets.py` — нормализация рынков (1X2, двойной шанс, тоталы, ИТ)
- `app/demo.py` — демо-данные без ключа
- `app/main.py` — FastAPI (`/api/sports`, `/api/odds/{sport}`, `/api/odds/{sport}/{event}/extra`)
- `static/index.html` — таблица
