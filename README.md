# Pinnacle Tracker

Отслеживание движения коэффициентов Pinnacle через [The Odds API](https://the-odds-api.com).

Раз в 30 минут сервер забирает **П1 / X / П2** Pinnacle по всем предстоящим матчам выбранных лиг и сохраняет снимок в SQLite.
**Двойной шанс 1X / 12 / X2** рассчитывается из 1X2: `1X = 1 / (1/П1 + 1/X)`.

- **Матчи** — текущий коэффициент и изменение от первого зафиксированного значения; клик — история всех снимков.
- **Просадки** — отдельный список исходов, у которых коэффициент упал от открытия на заданный % (по умолчанию ≥ 3%), самые сильные сверху.
- **Лиги** — какие лиги опрашивать (с оценкой расхода квоты).

Фиксируется только прематч: после начала матча снимки не пишутся.
«Открытие» — это первый снимок, сделанный трекером, а не реальное открытие линии у Pinnacle.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # вписать ODDS_API_KEY
.venv/bin/uvicorn app.main:app --port 8077
```

Открыть http://localhost:8077. Опрос идёт, пока запущен сервер; после перезапуска он продолжает по расписанию
(время последнего опроса хранится в БД `data/odds.sqlite`).

## Квота

Один опрос = 1 запрос на лигу (`markets=h2h`, `bookmakers=pinnacle`). Каждые 30 минут — 48 запросов/день на лигу,
≈ 1440/мес. Бесплатного плана (500/мес) хватит примерно на 10 дней для одной лиги — для постоянной работы нужен платный план
или больший интервал (`POLL_INTERVAL_MINUTES`). При остатке квоты меньше `MIN_QUOTA_REMAINING` опрос останавливается.

```bash

```

## Структура

- `app/poller.py` — фоновый опрос по расписанию
- `app/store.py` — SQLite (матчи, снимки, настройки)
- `app/movement.py` — изменение от открытия и список просадок
- `app/markets.py` — разбор рынков API, расчёт двойного шанса
- `app/odds_client.py` — HTTP-клиент The Odds API
- `app/main.py` — FastAPI
- `static/index.html` — интерфейс
